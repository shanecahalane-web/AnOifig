# Add An Oifig public marketing website and interactive Tara preview

Adds a standalone Next.js / TypeScript / Tailwind site under `frontend/`, separate from the Python backend and any future authenticated dashboard. Includes an original forest-green and gold design, responsive navigation, invoice draft/review/explicit approval simulation, workflow and feature sections, clearly planned roadmap, configurable unconfirmed pricing, FAQ, early-access/contact pages and marked legal drafts.

No official logo asset was available, so the name is displayed as text. No fabricated testimonials, counts or ratings. No live AI, messaging, payment or deployment integrations. Forms validate and download local enquiry drafts; they explicitly do not submit information or register users. Real signup/contact delivery, verified contact details and legal review remain release prerequisites.

Validation: production build, TypeScript, formatting, dependency audit (zero production vulnerabilities), and 14 passing desktop/mobile Playwright checks including axe accessibility scans on every page. Screenshots and reproduction instructions are in `frontend/docs/` and `frontend/README.md`. Backend source, dependencies, migrations and security rules are untouched; backend suites were not run.

The requested reference site could not be inspected because network access returned HTTP 403. No reference assets, copy or exact layouts were used. No merge or deployment is requested.
